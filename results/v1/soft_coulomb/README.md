# Soft-Coulomb potential

## Potential definition

The Soft-Coulomb potential is defined by the following equation:

$$
V(r) = -Z / (r^q + a^q)^{1/q}
$$

where $Z, a, q \in \mathbb{R}$ are parameters of the potential.
